# BOSS 求职模板 0.2.51（制作中）

通过 FlowArk 普通界面导入、配置和运行。包含十三个入口，每日入口120步；无需编辑 JSON、源文件或导出包。公开默认不带作者账号、城市、简历、Key、Skill、动作授权或运行历史。

## 首次使用

1. 导入标准ZIP、创建独立实例，填写自己的目标职位、期望城市、排除方向、月薪与时区。当前每日检索只支持一个明确目标职位，多目标不会静默只取第一项。
2. 月薪单位为人民币元/月：15–20K填15000–20000。网页K/k自动乘1000，额外几薪单独记录。与期望区间有交集即可进入后续匹配，谈薪由用户处理；计薪周期、币种或收入构成不明确则转待办。上下限0表示该侧不限制。
3. 绑定自己的浏览器、资料目录、已确认个人Skill版本、AI供应商和模型，在本机配置自己的Key。所有模型Token由该Key承担，不借用作者资源、不自动换模型。每日JD默认使用DeepSeek并关闭思考、输出上限8192 Token；换供应商前需在普通编排中选择支持的生成设置。
4. 先运行“核对当前求职账号”，对照实际网站核对姓名、手机号掩码及账号别名并提交。在本实例资源页预览并选择该次来源结果，保存后供每日入口引用；不自动跟随最新结果或其他实例。姓名与掩码不是平台唯一账号ID。
5. 每日入口填写资料目录内准确的简历相对文件名、配置城市序号和本批数量。打招呼额度默认0，范围0–150，0阻止执行；本批默认20，范围1–150。每日回复额度独立且默认0，不因运行每日入口而允许后续消息。
6. 七项动作默认禁止。按所用入口分别核对授权；目录、Skill确认和浏览权限均不自动授予招呼、附件或后续回复。动作更改、失败和取消按实际回执处理。

## 已有沟通与跨版本使用

可选普通表单包含：已沟通的完整职位链接、所属账号别名、手机号掩码、已用招呼日期及保守数量。非空资料须与当前实际账号一致；链接只排除重复岗位，不制造新实例的确认回执。已用数量仅在准确日期生效，与新实例当日意图保守累计，不表示网站剩余额度。

新版本创建独立实例，原实例状态和Run不自动迁移。先核对旧账号、完整岗位来源与未知操作，再通过表单配置已有沟通和占额。禁止用新实例、改别名或切换版本重发旧的reserved/unknown意图。旧实例、原始资料和既有记录保留。

## 每日入口行为

先核对固定配置与账号，按配置查找实际城市。城市入口只尝试点击一次，随后读取真实弹层分组；点击结果不明时也不重试，只有明确观察到弹层才继续。分组准确匹配后停止查找，回读选项并核对网页实际城市，绝不采用网站默认城市。

候选不足才有限滚动：每次最多2000像素，最多24次，等待并复验真实列表稳定后读取完整岗位链接，最多500项、队列最多1000条。每次Run只消费有限批次。入队、开始处理及最终分类均读取最新完整状态、按修订写入并重新核对回执；列表重排不会替代稳定岗位身份。

逐项按完整链接打开独立JD，核对账号、城市、职位、薪资、材料和固定Skill，经硬条件和自有AI建议后再次复验。符合才持久预留并准备唯一操作，核对最新来源后只点击一次“立即沟通”。BOSS可能使用账号配置的招呼语；请先在网站核对该内容与自己的最新资料。

点击后核对同一岗位的实际聊天、消息时间、送达/已读与关联职位来源，明确后才登记招呼确认并返回列表。不能核验则保留unknown、占额和待办，停止本Run且不重发。后续有限Run按稳定账号/完整岗位身份隔离旧reserved/unknown，并保留原操作与当日保守占额；其他岗位仍须独立核对条件、完整来源和最新修订。孤立未知、账本损坏、账号/时区变化或本地额度用尽仍整体停止，不从搜索无结果推断未发送。浏览详情、点击返回、模型匹配、脚本成功均不计确认招呼。

每日150次是打招呼上限，完成依据仅为BOSS网站真实的当日上限弹框。本机额度停止、候选耗尽或一个有限Run结束均不表示当天完成。简历附件只在对方回复后按独立路径处理，不计招呼数。

## 其他入口和边界

只读页面、条件、材料/Skill、网页JD来源/正文及方向评估可分别运行；来信处理、回复草稿、会话接管和回复前核对保留独立入口。模型只提供内部建议，不自行扩大动作授权。未知事实、冲突、岗位歧义、谈薪或超出自动回复边界交给用户，不编造经历、能力或承诺。

## 当前验收范围

已有实际账号选城、完整来源队列/CAS、JD模型评估，以及前版同账号六条真实招呼与聊天回执证据。原实例已实际验证旧未知岗位隔离、保守已用7和其他候选通过账本；本版仍在真实续批验证，普通连续城市时序、完整异常恢复和公共复导继续核对。自动跨有限Run续批、网站真实150次弹框、对方回复后简历附件和实时有序对话尚未完成，不作为已完成的全天自动求职产品交付。

需要支持正式0.49.0契约及模板所声明能力的FlowArk客户端。运行会操作真实网站并产生自己的API费用；具体范围、Token和结果在客户端查看。所有定义和普通配置通过UI维护，高级JSON仅供调试与高阶配置。
