# BOSS 求职模板制作检查点 0.1.3

通过 FlowArk 客户端可视化编排制作，包含三个手动入口。当前不执行投递、简历发送、聊天或不感兴趣动作，也没有模型调用。

1. 核对求职条件（只读）：在共享配置填写目标职位、期望城市、排除方向和月薪上下限。列表最多20项，每项1至100字符。月薪为人民币每月整数，0表示该侧未设置；不推断税前税后或其他币种。城市和排除项可空，目标职位至少一项。检测空白、同组重复、目标与排除完全相同、上下限冲突；不判断职业近义词或真实JD匹配。此入口无需浏览器、AI或Key；通过只表示条件一致性，不代表账号/完整JD/Skill/动作授权。修改配置后重新核对，同修订缺项提醒去重并保留首次来源。
2. 打开指定 BOSS 起点：先绑定自己的内置或已选浏览器，打开公开城市页并记录实际网址。起点城市不自动成为求职偏好。
3. 核对当前页面（只读）：读取网址、标题和可见正文，识别独立登录页或职位正文明确的登录遮挡。提示缺失不代表已登录、JD完整或账号已核验。需要登录时由本人完成后重新核对，不破解验证码或私有接口。

导入不自动运行或授权，浏览器初始解绑。每个实例独立配置；默认数组为空、薪资为0，不含作者偏好。所有未来模型消耗必须使用用户自己的Provider/model/Key；Key、个人Skill和简历不进入公开包。

后续继续制作真实账号、完整JD/会话关联、已确认Skill、用户Key、岗位判断及逐动作授权/去重/回执。当前仅为公共制作检查点，不代表完整招聘闭环通过。
