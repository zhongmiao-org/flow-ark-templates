# BOSS 求职模板制作检查点 0.2.6

通过 FlowArk 客户端可视化编排制作，包含八个手动入口。JD方向评估和来信处理使用用户自己的AI服务生成内部建议；其余六个入口无需模型。当前不执行投递、简历发送、聊天或不感兴趣动作。真实Key评估与完整业务尚待验收。

1. 核对求职条件（只读）：在共享配置填写目标职位、期望城市、排除方向和月薪上下限。列表最多20项，每项1至100字符。月薪为人民币每月整数，0表示该侧未设置；不推断税前税后或其他币种。城市和排除项可空，目标职位至少一项。检测空白、同组重复、目标与排除完全相同、上下限冲突；不判断职业近义词或真实JD匹配。此入口无需浏览器、AI或Key；通过只表示条件一致性，不代表账号/完整JD/Skill/动作授权。修改配置后重新核对，同修订缺项提醒去重并保留首次来源。
2. 打开指定 BOSS 起点：先绑定自己的内置或已选浏览器，打开公开城市页并记录实际网址。起点城市不自动成为求职偏好。
3. 核对当前页面（只读）：在同一次采集中读取页面来源、标题与明确正文登录提示，再分类并登记本人待办；不需要AI或Key。使用当前已校准的提示定位，缺失不代表已登录、JD完整或账号已核验，定位不唯一/观察不完整时转本人核对。仅明确登录路径或职位正文明确提示“登录查看完整内容”才登记登录待办。需要登录时由本人完成后重新核对，不破解验证码或私有接口。

本预检需要支持网页关联字段采集的客户端，使用FlowArk内置浏览器或明确选择的Chrome；Firefox/Safari当前会明确阻止该采集能力，不静默切换。仅标题与提示字段参与本次采集，不读取整页正文作为预检来源；查询串/片段和提示原文不复制到待办。根定位、导航、框架、语法或预算错误会停止本次运行，请查看失败原因及页面后再明确发起；不自动重试、不采用部分结果。账号与招聘动作资格始终未核验，不能将采集完整当作允许发送。

导入不自动运行或授权，浏览器初始解绑。每个实例独立配置；默认数组为空、薪资为0，不含作者偏好。所有未来模型消耗必须使用用户自己的Provider/model/Key；Key、个人Skill和简历不进入公开包。

后续继续制作真实账号、完整JD/会话关联、已确认Skill、用户Key、岗位判断及逐动作授权/去重/回执。当前仅为公共制作检查点，不代表完整招聘闭环通过。
4. 核对简历与固定Skill（只读）：为本入口选择只读简历资料目录、明确填写安全相对文件名（resumeFile），并选择本机已登记的准确Skill确认版本及摘要。支持UTF-8/PDF/DOCX，最多8MiB、100页、1000单元、50000字符，不扫描目录、不自动OCR。缺绑定、版本缺失或变化时阻止；partial/empty进入本人提醒，完整文档与Skill正文留在本机受保护结果。sources-ready只证明资料可读取及来源已固定，不证明身份/事实一致、账号/JD有效，不授权模型使用或发送。提醒按所选文件名/内容摘要、Skill摘要及解析状态去重。此入口不需要浏览器/AI/Key；其他入口不会因它而额外要求简历或Skill。

5. 评估JD与求职方向（建议）：填写明确选定的岗位名称、JD正文、完整性声明及可选来源备注；绑定本机固定确认Skill及自己的AI供应商/模型/Key。读取固定共享条件，缺口转本人；满足准备条件后调用结构化AI，并核对目标引用和JD原句，形成match/mismatch/review三路建议。未知、冲突、伪造原句或模型不确定转本人提醒。match仅准备后续草稿，mismatch仅准备独立不感兴趣建议，当前不外发、不点击；accountVerified/eligibleForActions始终false。来源备注/完整性声明不证明真实账号或会话来源，后续登录会话须独立读取核验JD。模板仅保存JD摘要、配置修订和实际Skill版本等来源；模型不能提供动作授权。提醒同来源去重并保留首次/已读。缺Key或未确认Skill时阻止，不使用开发者Key或静默换服务。

6. 处理来信与回复草稿（仅内部）：明确填写JD及来信正文，确认完整性并核对本人接管声明，并填写稳定的账号/会话来源键；默认空来信、未完整、接管中。必须先在独立控制入口明确核对恢复范围。模型前读取该会话持久控制状态，缺失或暂停、来源键/最新JD/来信摘要/求职配置修订不一致时转本人且不调用模型。先走JD三路建议，只有明确match后再用同一用户Key分类来信并起草，最多两次结构化模型请求。JD模型后、来信模型前再次读取控制状态；来信草稿后再读取一次。该会话代次或恢复范围变化即转本人、作废草稿，其他会话更新不单因全局修订变化而使草稿失效。普通事实/自我介绍/技术交流仅引用固定Skill原文生成最多300字符的内部草稿；引用缺失、未知、冲突、正式题目/身份质疑/承诺转本人并清空可采用草稿。索要简历只建立附件待核对建议，不声称已发送。原始模型建议另存用于核对，不直接发送。JD/消息摘要、配置修订、实际Skill版本随结果保存；来源声明不代表真实账号/会话或最新消息已核验，accountVerified/eligibleForActions始终false。无绑定时阻止，不借用作者Key，不静默更换服务。

来信入口尚未实际完成真实Key语义/故障矩阵。读取登录后真实会话及最新JD、本人接管生效、发送前复验、去重、简历附件与消息回执继续独立开发验收。导入不执行，个人资料与本机绑定不进入包。

AI请求故障：三个可见AI节点显式使用v2/result。成功后继续原句核对；认证、限流、HTTP、网络、请求超时、拒绝、不完整或无效响应转本人待办，保留失败阶段/分类、固定来源及已知回执/用量，未知为null，不推算为0。失败不形成岗位不符合结论，不提供可采用草稿，不继续第二次AI或执行招聘动作，不自动重试/换服务。取消、节点期限、缺Key/绑定、权限、输入/Schema、程序或存储异常仍中断；提醒存储失败不算已处理。相同来源与失败阶段去重保留首次/已读，正常重开不自动重跑。需要支持ai-outcome-v1能力的客户端；使用者仍须自行绑定AI和固定确认Skill。

来信入口显式声明template-sdk-v1与attention，以保存独立结果及本人待办；这些本机能力不授予招聘外发动作。

7. 会话接管与内部草稿恢复：填写稳定的账号来源键和会话来源键，默认暂停；恢复还须最新完整JD、来信正文并勾选本人核对。键来自本人明确输入，不靠AI猜测，尚未核验真实账号。首次无记录等同暂停；控制入口无需AI、浏览器或Skill，仅使用内部状态读写。使用者须在本入口明确允许“更新模板状态”动作，默认deny，不授予招聘外发权限。状态最多100条，按账号与会话组合隔离，CAS修订冲突停止、不自动覆盖或重试；重复暂停或相同范围恢复不改写代次、时间或全局状态修订。恢复只允许该范围的内部草稿，不自动处理新来信、发送消息或附件。

配置使用Run开始时的固定修订；新Run会对比恢复记录与本次配置。运行中只重新读取会话控制状态，不能据此宣称实时发现所有配置修改、站外本人操作，或撤回已发出的模型请求。不得将控制记录当作发送前原子锁；onmessage队列、实际账号/JD读取、发送前最后复验及effect去重/回执仍需独立完成。状态写入后结果保存失败须读取实际状态核对，不能自动重放。正常查看/重开不执行控制动作。

处理中需要接管时，先在“会话接管与内部草稿恢复”入口填写准确账号/会话来源键，选择暂停并点击“保存入口参数”；按需明确允许本入口“更新模板状态”动作。回到实例，选择该入口的“停止本实例后执行”，核对将停止的运行列表后确认。宿主先请求取消并等待资源回收，再创建控制入口的新Run；应查看控制入口实际结果，确认暂停记录已提交。已排队、已请求取消或等待回收均不代表暂停生效；取消或核对失败不会偷偷创建替代运行。

停止列表覆盖本实例内列出的全部运行，可能包含其他会话；只有持久控制记录按账号与会话隔离，不能把整实例停止说成只停止当前会话。其他实例不在该列表内。普通“运行”仍按单运行槽排队；页面没有停止后执行操作时，可在运行记录逐项取消要停止的Run，确认结束和资源回收后再运行暂停入口。取消不能撤回已产生的费用或已发生的站点动作。

核对范围、控制记录保存、恢复内部草稿和招聘外发是不同步骤。模型前后复查仅对已经提交的控制变化生效；恢复仍需最新完整JD/来信和本人核对，不自动发送、不重放旧草稿。此操作不证明真实账号、站外本人接管检测、细粒度会话取消或发送前原子锁已完成。

8. 核对当前网页JD来源（只读）：仅绑定浏览器；通过同次关联采集读取来源、标题、岗位及公司标签和明确登录提示。公司标签只是页面文字，不代表企业或账号身份核验。非站点、非职位页、缺失/重复字段和登录遮挡分别保留诊断与本人待办；查询参数不进入整理结果。没有登录提示仍不证明正文完整。当前入口不读取正文、不读取个人Skill、不调用模型；完整正文可见读取与本人核对后，才接续独立网页评估，当前不能代替它。

使用者只需通过客户端导入、创建实例、绑定自己的浏览器并运行来源入口；不要求编辑JSON。旧手动评估入口保持原行为，不能把手填JD当作网页来源。所有模型费用仍由使用者自己的Key承担；本批来源检查没有模型请求。正常重开不自动运行，重复来源提醒保留首次来源与已读状态。
