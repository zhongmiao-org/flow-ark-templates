# BOSS 求职模板制作检查点 0.2.25

通过 FlowArk 客户端可视化制作，包含十三个手动入口。使用者通过 UI 导入、创建实例、配置表单和资源，不需要编辑 JSON、源文件或导出包。当前未完成实际投递、简历发送、实时聊天、不感兴趣及网站当日上限验收。

本候选新增薪资字段与岗位硬条件步骤，已保存及检查语法，实际分流、原始包独立复导和完整故障矩阵尚未验证。

## 首次使用

1. 导入标准 ZIP 并创建独立实例。填写自己的目标职位、期望城市、排除方向、人民币月薪上下限、每日回复额度和明确时区。城市和职位默认空，薪资0表示该侧未设置，每日回复额度默认0；公开包没有作者个人城市或岗位。
2. 按入口绑定自己的浏览器、简历与项目资料目录、准确确认 Skill、AI供应商和明确模型，在本机设置中配置自己的 Key。全部模型费用由使用者自己的 Key 承担，不借用作者额度或静默更换服务。
3. 先运行“核对当前求职账号（本人确认）”，填写固定的本地账号别名，对照真实网页核对并提交。成功保存后，在本实例资源页完整预览并选择该次“已确认求职账号来源”，再保存绑定。只接受本实例同包的准确记录，不跟随最近结果，不复用其他实例、旧包或作者调试确认。
4. 每日入口默认额度0、批次20、城市序号1。额度范围0–150、批次1–150、城市序号1–20；共享城市/职位最多20项，每项1–100字符。0额度禁止进入候选浏览。账号结果未绑定时运行禁用；选中未确认、拒绝、变化或旧格式结果时，在首次网页导航前明确失败。
5. 实际选城运行前展开网页面板。每日入口的“打开求职城市选择”设置五分钟有限期限，包含首次三项浏览动作的逐项确认。过期、取消或来源变化即停止，旧确认不能继续；新Run重新核对。

## 操作入口

- 核对当前求职账号（本人确认）：仅需自己的浏览器。十二步等待必要账号字段非空后，同次采集姓名、手机号掩码、求职者简历入口和账号页标题。完整来源由本人确认或不采用；确认后重新采集比较，一致才保存，保存成功后登记通知。必要字段持续未就绪则等待失败；缺失、不唯一、来源变化不采用。人工请求最长十分钟，取消、超时或退出后失效。别名及掩码不是平台唯一账号ID，不得借改名清空旧意图或额度。

- 每日循环投递（制作中）：六十二步保留原条件/日期/额度检查，读取准确账号结果、校验确认状态，再打开当前账号页同次采集和比较，通过后才按配置选城。串行读取网站城市分组、分段及完整选项，精确匹配并回读；再按实际候选数量逐项读取标题/链接，独立读取JD与岗位城市，返回原列表复验城市、数量和本项身份。正文或公司来源缺口丢弃正文、通知并跳过，不计投递；城市、日期、身份或返回复验不符停止。运行开始的账号复验不代替实际招聘动作前再次核对。

每日逐岗硬条件：从同一独立详情采集唯一薪资原文，在返回列表并复验城市和本项身份后分流。常规K区间按月薪处理；千、万、元要求明确/月，年发薪月数单独保留，不摊入月薪，不猜税前税后或提成。薪资区间与用户设置完全分离则明确不符，整段符合已设置边界才通过；范围跨界、面议、其他币种/周期、乱码或缺失交本人。岗位标题与排除项精确相同才明确排除；目标精确一致只通过标题检查，别名或相似岗位仍待Skill语义评估。来源不完整仍不能进入评估。三态仅为跳过、通知核对或继续固定Skill评估，不授权投递或自动点击不感兴趣。

- 核对求职条件（只读）：检查空白、同组重复、目标与排除相同、月薪上下限和额度/时区。无需浏览器或AI，只验证配置一致性，不判断真实JD、账号或投递资格。

- 按配置打开职位页并选城：选择配置城市序号，从不带城市的职位页开始，读取网站真实目录、匹配完整名称、回读后选择并核对实际城市。不猜城市代码，不采用定位、Cookie或历史城市。缺配置、未匹配或回读不符停止。分组/分段/选项上界20/40/200，外层期限300000毫秒。

- 核对当前页面（只读）：同次采集来源、标题和明确登录提示。明确登录路径或正文提示才登记登录待办；提示缺失不证明已登录、正文完整或账号通过核对。登录、验证码由本人操作。

- 核对简历与固定Skill（只读）：选择目录内安全相对文件名和本机准确确认Skill版本。支持UTF-8/PDF/DOCX，最多8MiB、100页、1000单元、50000字符；不扫描目录或自动OCR。partial/empty交本人，来源可读不等于事实一致，不授权模型或发送。

- 评估JD与求职方向（建议）：填写选定岗位、完整JD和声明，绑定固定Skill及自有AI。最多一次结构化请求，核对原句、未知和冲突，形成match/mismatch/review内部建议；不点击投递或不感兴趣。

- 处理来信与回复草稿（仅内部）：填写完整JD、来信和账号/会话来源键，默认接管中。模型前、两次模型之间及草稿后复查持久控制状态。最多两次自有Key请求；固定Skill原文支持的内部草稿最多300字符。正式题目、身份质疑、承诺、未知或冲突交本人；索要简历只建立待核对建议，不发送消息或附件。

- 会话接管与内部草稿恢复：默认暂停；恢复须完整最新JD/来信及本人核对，仅修改内部控制状态，需单独授权“更新模板状态”。最多100条，CAS冲突停止，同范围重复不改代次。需要接管时核对“停止本实例后执行”的取消范围，等待回收后查看实际结果；排队或取消请求不表示暂停已保存、费用撤回或允许外发。

- 核对当前网页JD来源（只读）：只需浏览器，同次核对页面、标题、岗位、公司候选和明确登录提示。缺失、重复、遮挡或来源变化交本人；不读取正文、Skill或调用模型，公司候选不是企业身份核验。

- 核对网页JD正文（本人确认）：两级来源/登录检查后采集有限选区文字，隐藏、裁切或无法判定时拒绝。本人完整阅读并对照网页选择保留或拒绝，等待最长十分钟。目标最多4096字符、正文最多100000字符且受64KiB采集上限约束；超限整次停止，不截断。本人确认只是本次完整性声明，不授予招聘动作。

- 评估当前网页JD方向（本人核对后）：二十四步重新采集正文，由本人选择评估或拒绝。确认后重读元数据和全文，核对岗位、公司候选、路径和来源；变化、冲突或正文超过20000字符/65536字节停止。读取固定配置和Skill后最多一次自有Key请求，三路仅保存建议和待办。

- 回复前核对（制作检查点）：表单输入1–300字符完整回复，绑定浏览器。五步读取固定配置、最新控制/意图状态及网址，发现真实账号/会话/消息/职位/回执缺口后登记待办，始终不能发送；不预留、不写状态、不填写或清空输入，不调用模型。意图结构最多500条；unknown不自动重放或退还额度，记录满不自动清理。

## 运行边界

网页关联采集当前支持内置浏览器和明确选择的Chrome；Firefox/Safari缺能力时阻止，不静默切换。真实网站隐藏后台和其他浏览器仍须独立验收，当前选城连续运行需展开网页。结构定位变化时停止，不自动取第一项、猜字段、换驱动或重放未知动作。

候选位置只用于临时读取，不是持久去重键，相同数量不保证列表未重排。导航/点击回执不等于业务成功。每日三项浏览权限不包含沟通、消息、附件或实际招聘提交；新实例六项动作默认禁止，各入口范围分别核对。

AI认证、限流、HTTP、网络、超时、拒绝、不完整或无效响应交本人，保留实际回执/用量；未知为null，不推算为0，不形成不符合结论，不自动重试或换服务。取消、步骤期限、缺资源/Key/权限、程序或存储错误中断，待办保存失败不算完成。共享配置按Run固定，不能承诺实时撤回在途请求；正常重开不自动运行或重发。

账号可见来源不证明平台唯一身份。完整岗位条件、个人Skill、动作前账号/岗位/资料复验、持久去重/额度/effect、实际投递回执、翻页跨批及实时聊天仍待完成。本机计数、批次结束或用户额度耗尽不代表全天完成；最终以BOSS网站真实每日150次投递上限弹框为准。

公开包不含本人资料、确认Skill、Key、登录态、本机路径绑定、实际参数或历史。浏览器、资料和模型由使用者自己配置；个人Skill最终确认保存与招聘动作授权分别进行。
