# BOSS 求职模板制作检查点 0.1.11

通过 FlowArk 客户端可视化编排制作，包含六个手动入口。JD方向评估和来信处理使用用户自己的AI服务生成内部建议；其余四个入口无需模型。当前不执行投递、简历发送、聊天或不感兴趣动作。真实Key评估与完整业务尚待验收。

1. 核对求职条件（只读）：在共享配置填写目标职位、期望城市、排除方向和月薪上下限。列表最多20项，每项1至100字符。月薪为人民币每月整数，0表示该侧未设置；不推断税前税后或其他币种。城市和排除项可空，目标职位至少一项。检测空白、同组重复、目标与排除完全相同、上下限冲突；不判断职业近义词或真实JD匹配。此入口无需浏览器、AI或Key；通过只表示条件一致性，不代表账号/完整JD/Skill/动作授权。修改配置后重新核对，同修订缺项提醒去重并保留首次来源。
2. 打开指定 BOSS 起点：先绑定自己的内置或已选浏览器，打开公开城市页并记录实际网址。起点城市不自动成为求职偏好。
3. 核对当前页面（只读）：读取网址、标题和可见正文，识别独立登录页或职位正文明确的登录遮挡。提示缺失不代表已登录、JD完整或账号已核验。需要登录时由本人完成后重新核对，不破解验证码或私有接口。

导入不自动运行或授权，浏览器初始解绑。每个实例独立配置；默认数组为空、薪资为0，不含作者偏好。所有未来模型消耗必须使用用户自己的Provider/model/Key；Key、个人Skill和简历不进入公开包。

后续继续制作真实账号、完整JD/会话关联、已确认Skill、用户Key、岗位判断及逐动作授权/去重/回执。当前仅为公共制作检查点，不代表完整招聘闭环通过。
4. 核对简历与固定Skill（只读）：为本入口选择只读简历资料目录、明确填写安全相对文件名（resumeFile），并选择本机已登记的准确Skill确认版本及摘要。支持UTF-8/PDF/DOCX，最多8MiB、100页、1000单元、50000字符，不扫描目录、不自动OCR。缺绑定、版本缺失或变化时阻止；partial/empty进入本人提醒，完整文档与Skill正文留在本机受保护结果。sources-ready只证明资料可读取及来源已固定，不证明身份/事实一致、账号/JD有效，不授权模型使用或发送。提醒按所选文件名/内容摘要、Skill摘要及解析状态去重。此入口不需要浏览器/AI/Key；其他入口不会因它而额外要求简历或Skill。

5. 评估JD与求职方向（建议）：填写明确选定的岗位名称、JD正文、完整性声明及可选来源备注；绑定本机固定确认Skill及自己的AI供应商/模型/Key。读取固定共享条件，缺口转本人；满足准备条件后调用结构化AI，并核对目标引用和JD原句，形成match/mismatch/review三路建议。未知、冲突、伪造原句或模型不确定转本人提醒。match仅准备后续草稿，mismatch仅准备独立不感兴趣建议，当前不外发、不点击；accountVerified/eligibleForActions始终false。来源备注/完整性声明不证明真实账号或会话来源，后续登录会话须独立读取核验JD。模板仅保存JD摘要、配置修订和实际Skill版本等来源；模型不能提供动作授权。提醒同来源去重并保留首次/已读。缺Key或未确认Skill时阻止，不使用开发者Key或静默换服务。

6. 处理来信与回复草稿（仅内部）：明确填写JD及来信正文，确认完整性并核对本人接管声明；默认空来信、未完整、接管中。先走JD三路建议，只有明确match后再用同一用户Key分类来信并起草，最多两次结构化模型请求。普通事实/自我介绍/技术交流仅引用固定Skill原文生成最多300字符的内部草稿；引用缺失、未知、冲突、正式题目/身份质疑/承诺转本人并清空可采用草稿。索要简历只建立附件待核对建议，不声称已发送。原始模型建议另存用于核对，不直接发送。JD/消息摘要、配置修订、实际Skill版本随结果保存；来源声明不代表真实账号/会话或最新消息已核验，accountVerified/eligibleForActions始终false。无绑定时阻止，不借用作者Key，不静默更换服务。

来信入口尚未实际完成真实Key语义/故障矩阵。读取登录后真实会话及最新JD、本人接管生效、发送前复验、去重、简历附件与消息回执继续独立开发验收。导入不执行，个人资料与本机绑定不进入包。

AI请求故障：三个可见AI节点显式使用v2/result。成功后继续原句核对；认证、限流、HTTP、网络、请求超时、拒绝、不完整或无效响应转本人待办，保留失败阶段/分类、固定来源及已知回执/用量，未知为null，不推算为0。失败不形成岗位不符合结论，不提供可采用草稿，不继续第二次AI或执行招聘动作，不自动重试/换服务。取消、节点期限、缺Key/绑定、权限、输入/Schema、程序或存储异常仍中断；提醒存储失败不算已处理。相同来源与失败阶段去重保留首次/已读，正常重开不自动重跑。需要支持ai-outcome-v1能力的客户端；使用者仍须自行绑定AI和固定确认Skill。

来信入口显式声明template-sdk-v1与attention，以保存独立结果及本人待办；这些本机能力不授予招聘外发动作。
