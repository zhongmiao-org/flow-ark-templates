# BOSS 求职模板制作候选 0.2.36

通过 FlowArk 客户端可视化制作，包含十三个手动入口。使用者通过 UI 导入、创建实例、填写表单和选择资源，无需编辑 JSON、源文件或导出包。本候选已连接真实“立即沟通”点击节点；首次网站回执仍待实站校准，因此点击后保存未知记录并停止，不能作为完整每日循环投递成品。

## 当前行为与未完成范围

每日入口先按配置选择并回读网站实际城市，核对账号来源、独立岗位详情与JD、薪资、所选简历和固定确认Skill；通过硬条件、持久账本及自有AI评估后，再复验最新账号/城市/岗位/材料/Skill，按修订CAS持久预留并重读。预留占额度，不表示已投递。

随后准备稳定意图对应的独立首次沟通操作。只有本次execute为true，才在确认后重新采集同项JD与入口文字，核对岗位地址、标题、公司、城市、薪资、正文摘要和原预留。账号复验超过两分钟、跨日、来源变化、重复或已有未知操作均停止，不点击。

通过后只点击一次该职位的“立即沟通”。网站可能自动发送账号配置的首条招呼语，当前没有该内容的独立预览；这不是发送简历附件，也不包括后续聊天、联系方式或任何承诺。读取点击后的实际网址和有界页面文字，仅作为真实回执校准来源；当前固定登记unknown、本地待办并停止。页面跳转、点击返回成功或脚本正常退出都不证明已投递。

仍待完成：可信网站回执分类、未知记录核对恢复、完整循环和翻页/跨批、简历附件、实时来信处理与发送、不感兴趣，以及真实网站每日150次上限验收。不能以本机计数、批次结束、用户额度耗尽或单项未知停止替代最终验收。

## 首次使用

1. 导入标准ZIP并创建独立实例。填写自己的目标职位、期望城市、排除方向、月薪上下限、每日回复额度和明确时区。城市和职位默认空，不从网址、定位或旧履历推断当前求职城市。
2. 薪资表单单位为人民币元/月。例如期望15–20K，下限填15000，上限填20000，不填15或20；0表示该侧不限制。网站15–20K和15K–20K会自动换算，额外几薪单独记录，不摊入月薪。税前税后和提成未明确时不猜。
3. 按入口绑定自己的浏览器、简历与项目资料目录、准确确认Skill版本、AI供应商及明确模型；在本机设置配置自己的Key。全部模型费用由使用者自己的Key承担，不借用作者额度，不静默更换服务。
4. 先运行“核对当前求职账号（本人确认）”，填写固定本地账号别名，对照网页核对并提交。保存成功后，在本实例资源页完整预览、选择该次“已确认求职账号来源”并保存。只接受同实例同包的准确记录，不跟随最近结果或复制旧包/其他实例/作者调试确认。姓名与手机号掩码不是平台唯一ID。
5. 每日入口填写本次简历相对文件名；默认每日投递额度0、批次20、城市序号1。额度0–150，0禁止候选浏览；批次1–150，城市序号1–20。共享城市/职位最多20项，每项1–100字符。缺资源或动作授权时不能运行；选中未确认、拒绝、变化或旧格式账号结果时，首次网页导航前停止。
6. 新实例七项动作全部默认禁止。按所用入口分别核对并配置权限；选择目录不等于授权写入。首次沟通、简历附件、后续消息和联系方式分别处理，不能因授权浏览或确认Skill而扩大范围。每日回复额度默认0，独立于投递额度。
7. 实际选城连续运行需展开网页面板。打开城市选择节点设置五分钟有限期限，包含首次浏览动作所需的确认等待。超时、取消或来源变化即停止，旧确认不能继续；新Run重新核对。

## 操作入口

- 核对当前求职账号（本人确认）：仅需自己的浏览器。十二步等待必要账号字段非空，同次采集姓名、手机号掩码、求职者简历入口与账号页标题。完整来源由本人确认或不采用；确认后重新采集比较，一致才保存并通知。人工请求最长十分钟，取消、超时或退出使请求失效。缺失、不唯一、变化不采用；别名变化不能清空旧意图或额度。
- 每日循环投递（制作中）：九十九步。先核对配置/日期/额度及准确账号来源，按真实分组查找配置城市；当前分组准确唯一匹配后停止后续分组查找，再回读分组、城市并核对实际选城。缺失、重复、页面变化或超限停止，不固定城市、城市代码或拼音映射。独立查找期限300000毫秒；岗位浏览与提交仍由后续可视化节点执行。初读、预留前及提交前的JD均采用真实详情拾取并验证的唯一正文定位，页面变化时停止。按实际候选数量串行读标题/链接和独立详情，返回原列表复验城市、数量及本项身份；来源缺口通知跳过，城市/日期/身份不符停止。硬条件及账本通过后读取固定Skill并调用自有AI；明确符合才进入最新来源复验、CAS预留、独立操作、确认后JD复验及一次实际点击。当前读取网站结果后保存未知并停止，尚未打通全天循环。
- 核对求职条件（只读）：检查空白、同组重复、目标与排除相同、月薪上下限及额度/时区。无需浏览器或AI，只验证配置一致性，不判断真实JD或投递资格。
- 按配置打开职位页并选城：按配置城市序号，从无固定城市的职位页读取真实目录、精确匹配、回读再选择。分组/分段/选项上界20/40/200，外层期限300000毫秒。缺配置、未匹配或回读不符停止，不猜城市代码、不沿用历史城市。
- 核对当前页面（只读）：同次采集网址、标题与明确登录提示。只有明确登录路径或正文提示才建立登录待办；提示缺失不证明账号、正文完整或登录有效。登录和验证码由本人操作。
- 核对简历与固定Skill（只读）：选择安全相对文件名及准确确认版本。支持UTF-8/PDF/DOCX，最多8MiB、100页、1000单元、50000字符；不扫描目录或自动OCR。partial/empty交本人，可读不等于事实一致，不授权模型或发送。
- 评估JD与求职方向（建议）：填写选定岗位、完整JD及声明，绑定固定Skill和自有AI。最多一次结构化请求，核对原句、未知和冲突，保存match/mismatch/review内部建议；不点击投递或不感兴趣。
- 处理来信与回复草稿（仅内部）：填写完整JD、来信及账号/会话来源键，默认接管中。模型前、两次调用之间及草稿后复查持久控制状态，最多两次自有Key请求；有Skill原文依据的内部草稿最多300字符。正式题目、身份质疑、承诺、未知或冲突交本人；索要简历仅形成核对建议，不发送消息或附件。
- 会话接管与内部草稿恢复：默认暂停；恢复须有完整最新JD/来信及本人核对，仅修改内部控制状态，另需状态写入权限。最多100条，CAS冲突停止，同范围重复不改代次。取消请求或排队不证明暂停已保存、费用撤回或允许外发；等待任务实际回收并核对结果。
- 核对当前网页JD来源（只读）：同次核对网址、标题、岗位、公司候选及明确登录提示。缺失、重复、遮挡或变化交本人；不读正文/Skill、不调用模型，公司候选不是企业身份核验。
- 核对网页JD正文（本人确认）：两级来源/登录检查后采集有限选区文字，隐藏、裁切或不能判定时拒绝。本人阅读并对照网页选择保留/拒绝，最长十分钟。目标最多4096字符、正文最多100000字符且受64KiB采集上限约束；超限整次停止，不截断。本人声明不授予招聘动作。
- 评估当前网页JD方向（本人核对后）：二十四步重新采集正文，经本人选择后再次核对元数据、全文、岗位、公司和来源；变化、冲突或正文超过20000字符/65536字节停止。读取固定配置和Skill后最多一次自有Key请求，三路仅保存建议与待办。
- 回复前核对（制作检查点）：输入1–300字符完整回复并绑定浏览器，五步读取配置、控制/意图状态与网址，发现真实账号/会话/消息/职位/回执缺口后建立待办，始终不能发送；不预留、不写状态、不填写/清空输入、不调用模型。

## 首次接洽的未知项分流

仅核心必需经验/资格、明确硬条件和影响判断的实质事实冲突进入阻断未知或冲突列表；列表非空仍交本人。可选/加分经验、非核心接入细节和JD未提及的出差/工时不单独阻断首次接洽，也不据空白宣称已满足或虚构经历；后续有新信息再核对。已知薪资低于本人下限等明确不符不得被无关未知掩盖。当前仍是建议，后续必须复验来源与独立动作。

## 硬条件、来源与去重

薪资区间与已配置范围完全分离则跳过，整个区间符合边界才通过；跨界、面议、其他币种/周期、乱码或缺失交本人。千、万、元的表达要求明确/月。标题与排除项精确相同才明确排除；别名、相似岗位和职责混合仍须Skill评估，不能按单个词拒绝。来源不完整不进入模型；建议本身不授予动作。

投递意图最多500条，公开初始为空。稳定意图不含日期、批次、配置、Skill或账号别名，同账号可见来源/岗位不自动重复提交。confirmed、reserved、unknown、failed分别记录，当前均占当天本地额度；未解决预留/未知、损坏/未来日期/重复键、时区或账号来源变化、额度用完或容量满交本人，不自动清理、迁移、退额或重放。可见来源不能证明跨实例或手工投递的全局账号额度。

模板与运行绑定固定版本、配置和资源，运行中编辑不改已有快照。固定Skill版本不会随新版本自动替换。简历与Skill冲突、事实缺证据或材料待更新交本人，不编造经历；实际发送附件还需独立核对网站附件来源和范围。

## 运行边界

网页关联采集支持内置浏览器和明确选择的Chrome；Firefox/Safari缺能力时阻止，不静默切换。当前隐藏网页连续点击及其他浏览器仍须独立验收。结构定位变化时停止，不取第一项、不猜字段、不换驱动重放未知动作。相同列表数量不证明未重排，候选位置不是持久去重键。

AI认证、限流、HTTP、网络、超时、拒绝、不完整或无效响应保留实际回执与用量、交本人，不自动重试或换服务。未知用量为null，不能写成0。取消、步骤期限、缺资源/Key/权限、程序或存储错误会中断；待办写出失败不算完成。正常重开不自动运行或重发。

公开包不含私人资料、确认Skill、Key、登录态、资料目录内容、实际参数值或历史。最终以BOSS网站真实每日150次投递上限弹框为全天结束依据；当前尚未取得这一完整运行证据。
