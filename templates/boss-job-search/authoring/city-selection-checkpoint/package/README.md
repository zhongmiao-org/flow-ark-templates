# BOSS 求职模板制作检查点 0.2.14

通过 FlowArk 客户端可视化编排制作，包含十二个手动入口。使用者通过客户端导入、创建实例、填写表单、选择自己的资源并运行，不需要编辑 JSON、源文件或导出包。当前仍为制作检查点，未完成自动投递、简历发送、实时聊天、不感兴趣和网站当日限额验收。

## 首次配置

共享配置填写目标职位、期望城市、排除方向、人民币月薪上下限、每日回复额度和明确时区。数组默认空，薪资默认0，每日回复额度默认0；不存在作者的个人城市或岗位偏好。列表最多20项、每项1至100字符，目标职位至少一项；城市选择入口另要求城市非空。0薪资表示该侧未设置，不推断税前税后或币种。每日回复额度范围0–100，默认时区 Asia/Shanghai。

按入口选择自己的浏览器、简历与项目资料目录、已登记的固定确认 Skill、AI供应商及明确模型；Key 在本机设置中配置。所有模型费用均使用本人的 Key，不借用作者服务、不静默换供应商或模型。导入不自动运行或授权，资源初始解绑，动作默认拒绝；本机绑定、Key、个人资料、Skill正文、聊天、参数实际值及运行历史不进入公开包。

## 操作入口

1. 核对求职条件（只读）：检查空白、同组重复、目标与排除完全相同、月薪上下限和额度/时区。仅表示配置一致性，不判断职业近义词、真实JD匹配、账号或动作资格。无需浏览器、AI或Key。

2. 按配置打开职位页并选城：填写共享期望城市，在入口表单选择配置城市序号（从1开始，默认1，范围1–20）。读取本次固定配置，打开不携带城市的职位列表，串行读取网站实际城市分组、分段及完整选项，按名称精确匹配，重新回读分组和候选后点击，再核对网页实际城市。热门组同名候选优先，其他来源仍保留；不猜城市代码或别名。缺失、配置无效、网站不支持或回读不一致时停止并提示，不采用定位、Cookie或网站默认城市。成功只表示选城，账号、岗位和投递资格仍未核验。需要支持网页变量目标的客户端；本批真实网站仅验证内置浏览器显示网页面板时的连续运行，隐藏后台和其他浏览器仍须独立验证。分组/分段/选项支持上界分别20/40/200，外层累计期限300000毫秒，超出直接停止。

3. 核对当前页面（只读）：同次采集页面来源、标题和明确正文登录提示。只有明确登录路径或正文“登录查看完整内容”才登记登录待办；提示缺失不证明已登录、JD完整或账号通过核验。定位不唯一、来源变化、观察不完整或预算错误停止，不采用部分结果、不自动重试。登录和验证码由本人操作。

4. 核对简历与固定Skill（只读）：通过表单填写资料目录内明确安全相对文件名，并选择本机已登记的准确Skill版本和摘要。支持UTF-8/PDF/DOCX，最多8MiB、100页、1000单元、50000字符；不扫描目录或自动OCR。partial/empty登记待办；来源可读不表示身份或事实一致，也不授权模型使用或发送。无需浏览器和AI。

5. 评估JD与求职方向（建议）：输入选定岗位、完整JD及声明，绑定固定确认Skill与自有AI服务。条件准备后最多一次结构化请求；核对目标引用、JD原句、未知和冲突，再形成match/mismatch/review建议。符合仅建议准备草稿，不符合仅建议独立的不感兴趣动作，不确定交本人；不点击或发送。手填来源备注不证明真实账号、会话或网页正文。

6. 处理来信与回复草稿（仅内部）：填写完整JD和来信、稳定账号/会话来源键并核对接管声明；默认未完整且接管中。先用控制入口明确恢复范围，再在JD模型前、两次模型之间和草稿后读取持久控制状态。缺失、暂停、同会话代次或固定范围变化即交本人并作废草稿。最多两次自有Key请求；普通事实、自我介绍及技术交流仅引用固定Skill原文，内部草稿最多300字符。正式题目、身份质疑、承诺、未知或冲突交本人，索要简历只建立待核对建议。不会发送消息或附件，不声称本人已处理。

7. 会话接管与内部草稿恢复：显式填写账号/会话来源键，默认暂停；恢复还需最新完整JD、来信和本人核对。仅内部状态写入，需明确允许“更新模板状态”，不授予招聘外发。最多100条，CAS冲突停止，重复相同范围不改写代次；来源键未核验真实账号。需接管时使用本实例“停止本实例后执行”并核对运行列表，等待取消与资源回收后查看控制Run实际保存结果；停止范围可能包含本实例其他会话，不等于只中断当前会话。普通运行仍排队。已请求取消、已排队或恢复内部草稿均不表示暂停已保存、费用撤回或允许外发。实时onmessage、站外接管检测、细粒度取消和发送前原子锁尚待完成。

8. 核对当前网页JD来源（只读）：仅绑定浏览器，同次采集来源、标题、岗位、公司标签和明确登录提示。非站点、非职位页、缺失/重复字段或遮挡登记待办；公司标签不是身份核验。当前不读取正文、Skill或调用模型，不能代替完整网页评估；不把查询串复制进整理结果。

9. 核对网页JD正文（本人确认）：只需浏览器。两级条件检查同次元数据、登录遮挡与有限已排版正文，变化、空值、隐藏/裁切或不完整时停止。完整候选建立固定人工阅读请求，本人对照页面选择确认保留或拒绝；目标最多4096字符、正文最多100000字符并受64KiB采集上限约束，超限整次停止，不截断。等待最长十分钟；取消、期限或退出使旧请求失效，重开不自动继续。本人确认只是完整性声明，不调用模型或授予动作；作者调试不能代替正式实例人工分支验收。

10. 评估当前网页JD方向（本人核对后）：二十四个可见步骤重新采集正文，只有准备完整且同次来源一致才由本人选择本次评估或拒绝。确认后重读元数据及全文，比较职位、公司候选、路径、字段配置和摘要；变化、条件冲突、正文超过20000字符或65536字节时停止，不截断或概括。读取固定配置和Skill后最多一个自有Key AI节点，宿主预算可另行拒绝。核对原句和目标后可视化分流review/match/mismatch，三路只保存建议和待办，不发送、不点击、不写控制状态。旧手填JD不代替网页来源。

11. 回复前核对（制作检查点）：使用固定共享额度/时区，在表单输入1–300字符完整回复正文并绑定浏览器。五个可见节点读取固定配置、最新接管/意图状态、真实网址，检查来源缺口并登记中文待办。真实账号、会话、消息、职位、回执尚未校准，前次草稿缺普通UI固定来源选择，因此始终不能发送；不预留、不写状态、不填写或清除输入、不点击，也不调用模型。手填正文或网址不是发送来源证明。replyIntents仅为最多500条的有限结构，默认空，未实现CAS预留、effect准备与站点回执；unknown不自动重放或返还额度，记录满不自动清理。

12. 每日循环投递（制作中）：入口每日额度为0–150、默认0，批次数量1–150、默认20。0表示未开放额度；当前只核对固定条件与参数并在循环中读取网页城市，尚无筛选、提交、回执或跨批接续。批次数量不是成功投递数；全天完成以真实网站每日150次上限弹框为准，当前未完成。每次实际投递前仍须核对网页城市、当前职位和地点与本次固定条件一致；缺失、不一致或不确定时停止交本人，不沿用旧选城结果。

## 运行边界

网页关联采集当前支持内置浏览器和明确选择的Chrome，Firefox/Safari缺此能力时明确阻止，不静默切换；城市变量目标及真实业务的各浏览器条件仍单独验收。结构定位随网站布局可能失效，不自动采用第一项、猜测字段或换驱动重放。选城连续运行当前需在运行前展开网页面板，若资源变化使预检过期，先重新检查；这不是隐藏无人值守通过。

AI节点显式采用请求结果分支：认证、限流、HTTP、网络、请求超时、拒绝、不完整和无效响应交本人，保留固定来源、故障阶段及实际可取得回执/用量；未知为null，不推算为0，不形成不符合结论，不继续下一次模型或招聘动作，不自动重试/换服务。取消、步骤期限、缺Key/绑定、权限、程序、输入或存储错误仍中断，待办保存失败不算处理完成。

共享配置固定于Run启动修订，控制状态仅按既有节点复查；不能据此承诺实时发现配置变更或撤回在途请求。结果和提醒按稳定来源去重保留首次与已读；正常重开不自动运行、重发或覆盖历史。完整账号、正文、本人确认、真实Key语义/故障、简历附件、逐动作去重及站点回执分别验收，公开检查点不代表这些能力通过。
