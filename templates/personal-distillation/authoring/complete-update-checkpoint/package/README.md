# 个人蒸馏 · 完整来源与更新建议（0.7.0 制作检查点）

通过 FlowArk 界面导入、配置、对话、运行和核对，不需要编辑 JSON 或填写私人会话 ID。公开包不含作者简历、个人 Skill、聊天记录、Key、浏览器登录态或本机路径。

## 开始使用

1. 在资源页选择自己的「简历与项目资料」目录。在入口参数逐项填写 1–10 份相对文件名，可新增、删除、排序；保存后先运行「核对所选资料」。不会扫描整个仓库或执行项目代码。
2. 在本地设置保存自己的 API Key，再为「本人 AI 服务」选择对应供应商和模型。访谈、整理、试聊都使用自己的绑定，不静默切换服务，不把 Key 粘贴进聊天或模板。
3. 从「持续访谈与补充资料」开始，随后在「需要我处理」的会话面板直接回答。历史持续保存，可随时补充；每次聊天最多携带 12 轮历史，这不是访谈总次数上限。资料或规程变化时先核对再采用。
4. 没有补充时不必继续回答问题。进入「完整访谈来源」核对并固定现有全部来源，再到「整理完整来源并生成待确认Skill」选择自己的「完整访谈来源」。最近 12 轮聊天范围不能代替完整来源。
5. 「Skill 保存目录」默认采用自己的资料目录，可以另选或清除；明确保存后独立保留，不随资料目录变化。目录绑定、来源确认与 Skill 最终保存分别操作。

## 完整来源整理与继续

每批最多 8 次模型请求，采用校验通过的完整响应，保存草稿和准确位置后释放运行槽。未完成全部来源时不会创建 Skill。

在本次运行结果的「来源整理进度」继续：正常批次点击「核对后继续下一批」；失败或未知请求先查看请求记录，有完整响应时优先零调用采用，仍需另发请求时点击「核对一次新尝试」。核对页显示准确来源、片段、当前配置、历史用量和本次上限：续批最多 8 次，失败重试最多 1 次，完整来源结果为 0 次。

上限只约束该来源节点实例。关联运行仍从原入口的第一步开始，其他步骤的模型调用、文件或网页操作需要独立核对。请阅读整体范围，再确认本次执行；默认不勾选，不自动发起下一批。来源、规则、配置、任务或期限变化后重新核对。

确认回包未收到时点击「重试此次确认」，保持同一次请求身份，避免重复创建运行。未知不等于未发送，不能反复重跑、换入口或供应商来重放。取消或应用重启后保留进度，未完成请求不会自动重发。

全部来源覆盖且宿主证明通过后才创建待确认草稿。未知日期、未更新简历和未核实数值保留待确认，不强迫追加访谈或编造内容。最新本人更正优先；助手建议不能自动变成本人事实。

## 编辑、试聊与确认保存

在「需要我处理」核对正文、分类数据和来源，可逐项编辑或内部试聊。最后由本人确认，实际写出并登记成功后，才成为所选目录中的新确认版本；失败或结果未知时先核对原保存结果，不反复覆盖。

创建草稿、确认来源、内部试聊和最终保存是不同步骤，不授予招聘外发权限。访谈与来源整理的 Token 分别按供应商实际收据记录；失败、取消和重试也可能计费，未报告用量保留未知，不按零计，也不把调试失败成本当作稳定一次蒸馏估算。

## 后续补充与完整更新建议

可以随时继续同一会话补充；本人表示没有补充时不追加访谈门槛。补充后重新核对并固定完整来源，在资源页选择自己的「完整访谈来源」、本人 AI 服务、Skill 保存目录与「已确认个人 Skill」准确版本，再运行「完整补充来源更新已确认Skill」。

更新入口先读取固定父版本、检查结构，再把父正文、分类、原来源和准确引用作为初始内容，逐片段处理完整补充来源；每批最多 8 次。未完成只保存进度，不生成更新建议。父版本、来源或规则变化后按新任务核对，不能冒用旧位置。费用和恢复核对与上文一致，不自动重试未知请求。

只支持本包完整来源草稿的 data.version=1 且 facts、preferences、expression、boundaries、unknowns 为文本的确认版本；不支持的旧结构在读取之后、模型之前明确停止，保留原版本，不静默转换。超出输入或输出预算时保留进度，不截断旧内容。未知项继续标待确认，不要求反复访谈。

全部来源覆盖后保存独立更新建议，原来源保持并附本次宿主证明；未涉及的结构化手工字段保留。到「需要我处理」比较父版本、当前编辑与建议，各项默认保留当前内容，明确采纳需要的变化并核对正文/分类一致性，再内部试聊和最终确认。只有实际写出并登记成功才告知新版本保存成功，失败或未知先核对原结果。旧确认版本、旧 Run 和 BOSS 绑定不自动替换，BOSS 使用新版须另行明确选择。

来源、偏好、表达及边界均需本人核对，模型不能保证语义没有遗漏。制作、独立复导、受控供应商和真实 Key/完整来源/最终写出分别验收；本包仍为制作检查点，不代表完整更新或 BOSS 实际业务通过。

## 资料与回答边界

资料解析保留逐份来源和单元定位；正文合计 50,000 字符、上下文 192 KiB UTF-8。空文件、解析缺口及超预算先由本人调整，不静默截断。自动回复仅采用已确认事实和边界；正式面试题、重要承诺、不确定信息及身份质疑交本人或按真实助手说明处理。

需使用具备「来源整理执行范围核对」界面的新版 FlowArk。若结果页没有显示本次调用上限的核对入口，请先更新客户端。真实 Key、完整来源处理、语义核对、本人最终确认、独立复导和实际写出分别验收。nuwa 方法来源与改动见 assets/nuwa-source.md，原 MIT 许可见 assets/nuwa-LICENSE.txt。
