# 个人蒸馏（制作中）

先将 materials 绑定到本人明确选择的资料目录，在“核对所选资料”或访谈入口逐项填写1–10份相对文件名；可新增、删除、排序，不扫描仓库或运行项目代码。默认清单为空，需要本人选择。

Skill输出的 workspace 默认使用本人选择的 materials 资料目录；在资源页可见默认填入、可另选或清除，明确保存后才固定。已有保存值不会随资料目录变动。公开包只声明逻辑目录关系，不携带作者路径；需要支持目录默认来源的客户端（契约0.31.0）。

选择目录不授予Skill确认或模型权限。本人确认后才写入已选择的工作区；蒸馏和后续使用均使用本人配置的API Key。

每份保留来源与单元定位，合计正文最多50,000字符、上下文最多192KiB UTF-8。空文件、解析缺口或预算不足要求本人调整；不静默截断，不在资料不完整时建立访谈。

访谈使用同一清单和内容可继续，文件、顺序或内容变化会隔离；先本人确认访谈，再生成待编辑/试聊/明确确认的Skill。局部更新入口仍固定父确认版本，不替换旧版本。

当前为制作检查点，真实Key、多轮本人确认与完整业务仍待验收，请勿当作已完成模板发布。模型调用使用用户自己的Provider、model和Key，资料及工作区由用户选择；公开定义不包含个人资料、Key或本机绑定。
