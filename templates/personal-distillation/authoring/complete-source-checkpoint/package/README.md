# 个人蒸馏 · 完整来源（制作检查点）

通过FlowArk界面导入、配置、运行和核对，不需要编辑JSON或填写私人会话ID。公开包不含作者简历、个人Skill、聊天记录、Key、浏览器登录态或本机路径。

## 开始使用

1. 在资源页选择自己的资料目录（materials），逐项填写1–10份相对文件名；可新增、删除、排序，不扫描仓库或执行项目代码。先运行“核对所选资料”。
2. 选择自己的AI供应商、模型和已保存API Key。所有访谈、整理、试聊调用使用该绑定，不静默切换服务，不要求把Key粘贴进聊天或模板。
3. 在“持续访谈与补充资料”创建访谈，随后到“需要我处理”中回答。历史持续保存，可随时补充；每次模型使用12轮历史窗口，这不是总轮次限制。后续修改资料或指令要核对再采用。
4. 信息足够时停止追问，在会话界面核对并固定完整来源。再到“整理完整来源并生成待确认Skill”资源页选择自己的完整来源，不沿用聊天窗口选中的最近12轮。
5. Skill输出目录（workspace）默认填入本人选择的资料目录，可以另选或清除；明确保存后成为独立绑定，已有保存值不随资料目录变化。目录选择不代替Skill确认或模型授权。

## 完整来源整理

每批最多8次模型请求，保存草稿与准确位置后结束，不长期占用运行槽。未完成全部来源时不会创建Skill；查看进度并在运行核对页继续同一入口。未知结果或未提交响应必须先处理，不能靠反复点击重跑或切换供应商重放。

全部片段覆盖且宿主来源证明通过后才创建待确认草稿。未知月份、未更新简历的经历、未核实数值保留待确认，不继续强迫访谈或编造内容。最新本人更正优先；助手建议不能自动变成本人事实。

在“需要我处理”核对正文、分类数据、来源，编辑或内部试聊，最后由本人确认，才向所选工作区写出新版本。创建草稿、确认来源、内部试聊和最终保存是不同步骤，不授予招聘外发权限。查看实际token用量：访谈与来源整理分别记录，未报告的用量显示未知，不能按零计。

## 后续补充与边界

可以继续同一会话。新增内容需重新固定完整来源并明确生成或更新，不自动覆盖旧Skill或BOSS模板绑定。现有“固定确认版本的局部更新”仍属于独立旧入口，完整增量合并、冲突与新版显式采用尚待验收；本包是制作检查点，不代表完整更新闭环或BOSS业务通过。

资料解析每份保留来源/单元定位；合计正文50,000字符、上下文192KiB UTF-8。空文件、解析缺口和超预算先由本人调整，不静默截断。自动回复仅使用已确认事实和边界；正式面试题、重要承诺、不确定信息及身份质疑转本人或按真实助手说明处理。

需要支持完整来源整理及公开提示词绑定的客户端（契约0.35.1）；真实Key、本人最终确认、独立复导和实际写出分别验收。nuwa方法来源与改动见assets/nuwa-source.md，原MIT许可见assets/nuwa-LICENSE.txt。
